## 3. 呼吸与光的空间传播（真实录屏逐帧测量）

工具：`screenshots/phase15f/lag.py`（ffmpeg 解码 10fps → 分区亮度 → 去趋势 → 互相关求相位滞后）

```
key    amp(p95-p05)= 5.63  std=2.05
spine  amp= 9.25  std=3.29
glass  amp=17.48  std=6.13
route  amp= 3.97  std=1.43
row1   amp= 3.25  std=1.18

相位滞后（相对页面顶部）：
  key → spine : 0.60s  相关 +1.00
  key → glass : 0.80s  相关 +0.99
  key → route : 2.00s  相关 +0.99
  key → row1  : 2.30s  相关 +1.00

glass 主导周期 ≈ 11.00s（自相关 +1.00）
```

结论：

- **周期 11.00s**，与 15e 的 A/B 结论一致。
- 五个表面是**同一个波形、依次延迟**（相关 +0.99~1.00），因此读作"一束光自上而下经过"，而不是"整屏一起明暗"。
- 幅度按材质分化：玻璃 17.5 > 金属 9.3 > 哑光 4.0 > 行 3.3。玻璃是金属的 1.9 倍、哑光的 4.4 倍，符合 DESIGN.md §3 的判定（1 : 2 : 0.4）。
- 15e 的下半段幅度是 10–15 级（深色），15f 路线 3.97 是**刻意降低**：路线是哑光面，过亮会变成"发光条"。

## 7. 已知缺陷 / 未验证

1. **headless screencast 在转场中段丢帧**（§4 注），需要真机复看一次录像。
2. **路线底条需要图例**：`底条长度 = 分钟数` 目前只在标题右侧以小字说明。
3. **移动端路线只显示 3 段**，横向滑动才发现其余 6 项（已加右侧渐隐，但没有"N 项"计数提示）。
4. **浅色材质幅度** 3–5 级，低于深色的 10–15 级；这是白底物理限制，未强行拉高。
5. **深色触摸按下的单帧**仍以 CDP 状态 + 浅色截图为主证据，未做逐帧标定。
6. **未重构其它页面**（按要求只交付 Today 原型）。
