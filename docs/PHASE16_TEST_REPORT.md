## 四、生产构建巡检做了什么（不是拿测试钩子摆样子）

`scripts/phase16-prod-accept.mjs`，跑在 `dist`（生产构建）+ 干净 Edge profile 上：

1. 打开 `#import` 对话框，把一份 32 词的 CSV 塞进 `<input type=file>` 并触发 `change`，走应用自己的解析路径 → 预览「32 个有效词 · 0 个重复 · 0 格式问题」→ 点「确认导入」→ 词库出现。
2. 回首页点「生成今天的计划」，真实生成 5 项任务（预览 / 回忆测试 / 拆句 / 写作 / 收尾）。
3. 逐页巡检 14 个入口 × 3 宽度（1366 / 1440 / 1920）× 2 主题，抓可见文本、属性文案、横向溢出（只统计「会被裁掉的文字」：容器 `overflow` 为 hidden/clip 且文字越界 > 2px）、控制台 `error`/`warning`/未捕获异常。
4. dark 和 light 各走一遍真实训练：预览 → 预览完成 → 答题 → 答错反馈 → 结果页，逐态截图。
5. 阅读页粘贴一篇真实短文并保存，回到阅读库。

截图：`screenshots/phase16/prod/`（25 张，含导入对话框、14 个页面、5 个训练态 × 2 主题）。

## 六、过程中发现并修掉的非文案问题

1. `index.html` 缺 `mobile-web-app-capable`，控制台一直报 deprecation 警告 → 补上，控制台 0 报错。
2. 上线页底部出现开发用原型切换器 → 改为只在 URL 带 `?proto=` 时渲染。
3. 推荐理由徽标把 `reasonZh · reasonTag` 拼在一起，中英并排 → 只显示中文，`reasonTag` 字段也统一中文。
4. 对比度脚本在主题过渡中途采样，把 `.d-quiet` 的过渡中间色当成最终色，误报 3 处 2.25:1 → 改成等页面所有动画/过渡结束后再采样；实测该按钮 `rgb(164,177,192)` 对 `rgb(8,9,11)` ≈ 8.6:1。

## 七、边界与遗留

**没有被削弱的东西**

- 所有「不保证 / 估算 / 答对一次不算掌握 / 自评不算掌握 / 照抄不算独立」的边界表述都保留，只改措辞（`tests/` 里对应的断言逐条核对过）。
- 题目数据、评分逻辑、学习算法、数据库版本未改；Phase 15h.1 的语义标记与 Phase 15h.4 的页面状态同步都还在（398 条测试全绿）。

**仍然是遗留的**

1. 语法页 34 个语法点仍是「卡片阵列」，不是按先修关系画出来的二层链——这是产品决策，Phase 16 没动。
2. 移动端只做了「不溢出、不重叠」门禁，没有做长文/万词库/长期数据下的密度测试。
3. 无头 Edge 取证：hover / focus / pressed 的逐像素证据仍是规则层，没逐态取像素。
4. 键盘路径没有逐键跑完整流程（Phase 15h.4 起就记在这）。
5. AI 相关页面在巡检里只验证了「未配置」状态，没有接真 Key 跑生成。
