# 词间 v1.5 界面设计

审计基线为 v1.4.0，提交 `327d327c31e2f68955deebb482a215f0152b5683`。工作副本、回环端口和 Edge 配置均隔离。截图里的词汇来自 4,716 条试用词书，阅读使用项目自己的验收短文，报告使用该隔离库实际产生的记录。无样本时显示空态。

## 先解决的三个问题

1. **高 · 移动端导航挡住学习。** 390×844 基线中，展开的 14 项导航占约 720px，词库根文档宽度达 504px。改为可收起、支持键盘的导航，窄表格自身滚动。
2. **高 · 今日操作顺序与布局脱节。** 未生成计划时，空任务卡和时间柱占据首屏，设置时间的表单约从 760px 开始。把预算、状态和生成入口放在同一段。已有计划时显示下一项、真实进度与任务队列。
3. **中 · 层级和阅读环境受材质干扰。** 词库空态被包在空表与高阴影面板里，报告的空记录和真实数据区视觉重量接近。减弱边界与反光，保留证据类型和空态。训练和阅读切换时只更新当前视图。

## 两套原型与取舍

| 维度 | A · Cinematic Workspace | B · Editorial Learning Studio |
|---|---|---|
| 视觉辨识度 | 深蓝工作台、两栏并行、设备式控制面 | 暖纸和松绿色、行线与书页层次 |
| 审美完成度 | 面板层次强，窄区需要更多断点和对比度校正 | 标题、词头和正文的层级更稳定 |
| 高频学习 | 时间和计划可并列，预览要在释义和选择间横向扫视 | 预算和主行动相邻，词头和选择按纵向阅读顺序排列 |
| 阅读舒适度 | 控制面的框线保留较强的存在感 | 正文靠字号和行长居中，辅助面板退居边缘 |
| 实施与维护 | 响应式栏位和材质状态多 | 一套控件和少量页面布局即可覆盖 |

采用 B。普通操作用稳定的中性色，松绿色标记当前导航、主行动和焦点，正误分别保留文字与形状。英文词头和正文可用衬线，中文界面、表单和数据沿用清晰的系统字体。

## 实施契约

- `tokens.css` 定义主题与尺寸，`ui/system.css` 定义外壳和原语，`ui/pages` 定义页面增量。依赖仍在的旧版结构保留，撤出验证无活跃入口的电影感 Today 路径。
- 今日进度来自真实任务。词库、报告与备份的读写契约以 v1.4.0 为准，数据库保持 DB9。
- 普通操作用短按压和选中反馈。原句阅读、编辑和连续答题期间避免页面级入场。减少动态效果由浏览器偏好控制。
- 验收矩阵涵盖桌面 1920×1080、1440×900、1366×768 和 390×844，明暗两套。校对题目交互、写入证据、弹窗可达性和表格滚动边界。
