# Phase 15h · 全站视觉复核

复核人：Hermes（本机 headful Edge 截图 + 计算样式探针 + `impeccable detect`）
复核对象：分支 `phase15h-full-ui-migration`，14 个页面 × 深/浅 × 3 尺寸，加 2 张阅读态。

**这份复核不宣布"审美目标达成"。** 结论只覆盖可被证据支持的部分：层级、材质是否成立、可读性、噪声、诚实性。

---

## 1. 结论（先给判断）

| 维度 | 判断 | 依据 |
|---|---|---|
| 是否还像"通用后台模板" | **基本不是** | 导航是一条轨道而非 14 个描边按钮；Today 的金属柱/玻璃面板/哑光路线是自有构图；页面之间的光与材质一致 |
| 视觉中心是否与学习中心一致 | **大部分是** | 词汇训练：词是唯一 62px 元素；阅读：正文 65ch 占主导；例外见 §3.1 |
| 材质是否"有物理理由" | **是** | 金属只在预算柱、主按钮、导航指示条；玻璃只在"当前任务"面板；哑光给列表。没有为了好看乱贴 |
| 浅色是否"白底加灰雾" | **不是** | 浅色底 `#E1E7EF` 偏冷，面板比底色亮一档并有 1px 边光，金属柱在浅色下仍是深色（有理由的重心） |
| 证据是否诚实 | **是** | 空样本一律 `—`；四段证据条用线型区分（实/虚/暖/冷）；学校成绩标 self-reported；兴趣明确写"不改变能力估计" |
| 是否有廉价 AI 味 | **已清掉主要来源** | 24 处 3px 左色条、弹性回弹、三处零偏移彩色光晕全部移除，活页面 `detect` 为 0 |

## 2. 逐页速判（只写有证据的）

- **home（A）**：三对象构图成立——左侧 248px 金属时间柱、右侧玻璃"当前任务"、下方哑光路线。问题：禁用按钮曾是 2.25:1，几乎不可见，已修。
- **books（B）**：表头/行节奏修过一轮后密度合适；空结果是可行动的内联入口，不是死文案。
- **weak（B）**：列表密度与 books 一致，没有另起一套视觉。
- **quiz（B）**：词是唯一视觉中心，四选项是键位，正误同时用 ✓/✕ + 语义线 + 文案（不只靠颜色）。
- **sentence / grammar（B）**：句式操作区与图谱共用同一套节点/边语言，不抢主区。
- **reading（C）**：见 §3.2、§3.3，本轮改动最大的页面。
- **input / output（B/C）**：编辑器零动画，自动保存是静态状态，自评用虚线证据标签。
- **unit（A）**：阶段轨道是本页唯一"仪式感"元素；空态不假装有材料。
- **diagnostics / stats（A）**：空样本 `—` 而不是 0 高柱；四段证据条线型区分。
- **exam（B）**：官方/自编徽章分层，不混为一谈。
- **ai / settings（C）**：来源可辨（本地/规则/AI），危险区物理隔离。

## 3. 具体缺陷与处理

### 3.1 无单一视觉中心（unit / settings 空态）
标题、警告条、空态卡、白色主按钮四方竞争。**未修**：这是信息架构问题（先有材料才能建单元），
需要产品决策而不是调权重。已记入遗留项。

### 3.2 阅读页的"辅助栏压迫正文"（已修）
初次阅读态复核：右栏是一堆带边框的小方块（标记 2×2、难句 3 列、帮助 2×2），像表单，抢注意力。
处理：右栏外层去边框/去底色/去阴影，只留一条左侧 1px 分隔；组标题用线分隔；键位去边框靠留白与 hover；
虚线空状态去掉（虚线是"待填表单"的语言，不是"还没标记"的语言）。改后复核：右栏"已降为安静的辅助信息"。

### 3.3 阅读正文排版（实测达标，未改）
`#read-text`：宽 **622px**、字号 **19px**、行高 **33.06px（1.74）**、约 **65 字符/行**。落在舒适区。
深色下正文与底对比充足；元数据偏弱（设计上就该弱）。

### 3.4 禁用态几乎看不见（已修）
Hero 的"重新生成未完成部分 / 调整预算"禁用时 **2.25:1**（fg 65,75,88 on 8,9,11）。
WCAG 对 inactive 组件有豁免，但 2.25 读起来像"页面缺了一块"。改为 `--ink-faint` + 0.72 透明度，
对比度回到 4.5 以上，视觉上仍明显是禁用态。

### 3.5 空状态信息量过低（部分修）
books 空结果已给两个真实入口；unit 空态仍是一大块说明文字，**未修**（同上，需产品决策）。

### 3.6 导航密度
14 项常驻。这是产品范围（词汇→句法→阅读→输入→表达→单元→诊断→迁移）决定的，不是视觉能削减的。
目前用 2 级分组（学习 / 数据）和 13px 字号控制，**仍偏密**，记入遗留项。
