# Phase 15f · Art Direction（设计过程与裁决记录）

基线：`phase15e-cinematic` / `ef4e43f` → 分支 `phase15f-art-direction`
本文件回答三件事：**用户说的每条问题，用什么设计动作回应了；哪些 Skill 流程真的跑了；哪些地方仍然没做到。**

---

## 1. 用户反馈 → 设计动作

| 反馈 | 设计动作 | 结果 |
|---|---|---|
| "整体构图仍然过于传统" | 拆掉全宽 Hero，改成 **金属立柱 + 玻璃板 + 哑光路线 + 账页** 三件物体；立柱与玻璃板在同一 row 等高 | 首页不再是一张矩形；视口左上是"还剩多少时间"，右侧是"现在做什么" |
| "Hero 是一张巨大的渐变矩形" | Hero 变成**两层材质**：左侧 248px 金属立柱（68 + 竖向量尺 + 完成环）、右侧玻璃板（任务 + 理由 + 主按钮）；两者贴合而非并列 | 视觉重心从"一块大渐变"变成"一件金属 + 一块玻璃" |
| "光照运动没有体现材质物理特性" | 四种材料各自的关键帧：金属=竖向窄镜面带（振幅 9.2 级）、玻璃=横向光带（17.5 级）、哑光=漫反射（4.0 级）、纸/控件=行级柔光（3.3 级） | 同一束光，四种反应；幅度比 1 : 2 : 0.4 |
| "学习数据和任务结构没有融入视觉" | 时间预算做成**竖向量尺**（150′ 总长 / 68′ 填充 / 82′ 斜纹余量 / 圆点在 45% 处）；今日路线做成**等宽段 + 底条长度=分钟数** | 数据不再是"数字 + 标签"，而是长度和位置 |
| "浅色主题缺少精密材质反差" | 浅色下**金属立柱保持深色**（#20262E→#0F1319 拉丝），白玻璃板浮在 #E1E7EF 冷灰底上；路线段是独立白面 + 投影 | 浅色不再是"白底灰雾"，而是深金属 vs 白玻璃 |
| "移动端需要独立界面设计" | 移动端换成横向时间条（68 + 横向量尺 + 0/9）→ 整宽玻璃板 → 横向吸附滚动的路线卡带 → 明细 | 首屏顺序按手机阅读重排，不是压窄桌面 |
| "配色克制 ≠ 表现力克制" | 强调色仍只有冰蓝 + 琥珀（占屏 < 3%），但光的位移、材质对比、接触阴影全部放大 | 色相数量没变，画面强度变了 |

## 2. 构图与数据的绑定（避免"为了炫酷加假数据"）

- **68** = `remainingMinutes`（今日路线待完成分钟数），由 plan 里未完成任务的分钟数求和。
- **150** = `budget`（用户选的时间预算）。
- **82** = `budget − remainingMinutes`，标签是"未安排"，不是"已用"。
  15e 曾把它标成"已排"，是错的：任务总和只有 68。
- **0/9** = `done / total`。
- **路线底条** = `task.minutes / max(task.minutes)`，当前项不改变底条长度（状态用描边表示，不与数据编码抢同一通道）。

三处数字全部来自已有数据，没有新增指标。

## 5. 仍然没做到的（诚实清单）

1. **录屏证据有硬伤**：headless Edge 的 `Page.startScreencast` 在 `backdrop-filter`/多层合成上会丢帧，转场中段会出现 3–4 帧接近黑；逐帧 `captureScreenshot` 复测无此现象。DOM trace 证明时间线没有空档。**需要在真机（GPU 合成）上复看一次录像。**
2. **路线的"底条编码"要第二眼才读懂**：底条 + 数字同时存在，仍需图例。
3. **浅色材质运动幅度天然偏低**（3–5 级 vs 深色 10–15 级）：白纸只能靠"影子经过"表达受光。
4. **移动端路线只露出 3 段**，其余靠横向滑动；未做"还有 6 项"的显式提示。
5. **没有做 Reading 之外的页面重构**（按要求只做原型）。

## 6. 为什么不引入新渲染技术

| 方案 | 评估 | 结论 |
|---|---|---|
| View Transitions API | 同文档可用；跨文档 Firefox 不支持；现有 FLIP 已 0 掉帧 | 不引入 |
| WebGL / Canvas 光场 | 需要额外上下文与逐帧 rAF，功耗上升；当前合成层已 4.95ms/帧 | 不引入 |
| `@property` 驱动光变量 | 可行，但会让整棵子树每帧重算样式 | 不引入（改用各材料独立关键帧 + 相位） |
| 动画库（Motion/GSAP） | 本页只有 4 段关键帧与 3 个交互，CSS 已足够 | 不引入 |
