## P0-1 文字过小

**症状**：15d 有 108 个文本节点，80 个（74%）在 12px 以下（9 / 9.5 / 10.5 / 11 / 11.5）。

**改动**：
- 建立 5 档内容字号：`--d-fs-caption 12` / `--d-fs-meta 13` / `--d-fs-body 14` / `--d-fs-lead 16` / 标题 `clamp(24px,3vw,34px)` + 时钟 `clamp(56px,8.2vw,104px)`。
- 读数带、时间带标题、行备注、按钮、行序号全部提到 ≥12px；只有装饰性刻度（时间段里的 `01–09`，10px）保留小字号，且移动端直接隐藏。
- 读数带改成语义化文案：`已完成 / 项`、`完成率 / 本段`、`已排 / 预算分钟`，删掉 3 个孤立的单位小字（`项` / `本段` / `分钟`）。

**证据（CDP 实测）**：
- 桌面深色/浅色：`textNodeCount 105, tiny 0`；字号分布 `12×77, 13×10, 14×9, 16×1, 19×3, 22×3, 34×1, 104×1`。
- 移动端 390：`tiny 0`；字号 `12×25, 13×44, 14×9, 16×1, 18×3, 19×3, 24×1, 74×1`。
- 对比度：`checked=226 failures=0`。

## P0-4 触控反馈

**症状**：15d 的 `living.ts` 对 `pointerType === 'touch'` 直接 `return`，手机上整套交互光不启动，只剩慢速明暗。

**改动**：
- 新增 `bindTouchGlow()`：在触摸点生成一个 180px 的柔和光斑（`screen` 混合，深色 .52 / 浅色 `multiply`），按下时 scale .4→1、透明度 0→1（220ms），松开后自然衰减。
- 行加 `.is-pressed`：底色抬亮 + 1px 内描边；松手回到常态；展开后 `.is-open` 保留选中态。
- 所有 `:hover` 规则包进 `@media (hover:hover) and (pointer:fine)`，触屏不再模拟悬停。

**证据**：
- CDP 触摸探针：按下时 `.d-tap` 存在、`opacity 1`、行 `is-pressed=true`；松手后 `is-pressed=false`、行 `is-open=true`。
- 截图 `screenshots/phase15e/stills/touch-pressed.png`：被按行变白、有琥珀描边、触点处有柔和高光。

## P1 动态光影与呼吸

**根因**：15d 的光全部在 `.d-stage` 内部，`overflow:hidden` 把光裁在舞台里；读数带、时间带、任务行在舞台之外，永远收不到光。所以"下半舞台几乎不可见"不是幅度调小了，是**结构上照不到**。

**改动**（不加光球、不加扫描线、不加霓虹）：
1. **一束光，四个落点**：`.d-tide.t1/t2`（页面级，t1 从上往下走、t2 在地面反相）、`.d-undersky`（舞台底部反光）、`.d-catch`（读数带/时间带表面受光）、`.d-page::after`（地面光池）。全部同一个 `--d-breath`、同一相位。
2. **上下光照联系**：顶光 `.d-sky` 在 50% 相位最暗，`.d-tide.t1` 在 50% 到达底部最亮，`.d-undersky` 与地面光池同时最亮。物理上是"光从上面移下来了"，不是两个独立呼吸。
3. **材质受光方向统一**：读数带、时间带、任务行的受光层从"顶部径向光斑"改成 `linear-gradient(180deg, …)`，与舞台同一个自上而下的方向；并用 `translate3d` 做 -30%→+2% 的缓慢下移。
4. **浅色主题**：白色表面无法"变亮"，所以用 `multiply` 的暖灰淡影（`rgba(74,62,46,.175)`）表现"光经过时纸面的明暗"，而不是靠加白。
5. **阅读页**：从"24s 慢速环境光"改为**完全静止**（0 个 `@keyframes`），只保留静态的层次渐变。

**呼吸周期 A/B（真实录屏，15s/条）**：

| 候选 | 下半舞台幅度 | p90 帧间变化 | 判断 |
|---|---|---|---|
| 9s | 10.3 | 0.833 级/0.1s | 偏快，接近"脉动" |
| **11s** | **10.4** | **0.662** | **采用**：可见、但不是脉冲 |
| 15s | 10.4 | 0.486 | 单次注视下接近不可见 |

（同一构建、同一机位、同一主题；幅度按屏幕四段取 p95−p05。）

**最终实测（16s 空闲，1440×900）**：

| 区域 | 深色幅度 | 深色 p95 帧间 | 浅色幅度 | 浅色 p95 帧间 |
|---|---|---|---|---|
| 舞台上部 | 4.27 | 0.19 | 0.71 | 0.06 |
| 舞台中部 | 1.43 | 0.10 | 1.00 | 0.07 |
| 舞台下部 | 10.07 | 0.46 | 5.30 | 0.26 |
| 读数带 | 13.74 | 0.73 | 3.20 | 0.19 |
| 时间带 | 14.87 | 0.79 | 3.97 | 0.23 |

- 下半部分从 15d 的 0.29–0.40 级（不可见）→ 10–15 级（深色）/ 3–5 级（浅色）。
- 帧间变化 p95 ≤0.79 级，无闪烁；15s 内只有 1 帧 >6 级，是录屏采集丢帧，不是渲染跳变。
- 时间带/读数带的受光与舞台同相位：抽帧可见 F1/F8 顶部最亮 → F4/F5 底部+读数带最亮 → F6/F7 回升。

## P2 共享元素与物理时间线

**15d 的问题（帧证据）**：前 23% 时长走完 80.6% 位移；98.3% 在 323ms 完成，之后 333ms（58% 时长）只移动 5px；412ms 处新旧两层同时可读。

**改动**：
1. **曲线**：几何改为 `smoothstep` + 末段 1.2% 阻尼收尾（起步慢、中段快、落定稳），不再是欠阻尼弹簧。
2. **内容交接**：旧内容 0–100ms 退场；新页面 160–405ms 才淡入；两者永不重叠。
3. **单帧交接**：420ms 时容器与目标同矩形，容器移除，真实 DOM 已就位。
4. **材质连续**：容器内叠一层"目标材质"，随几何进度 15%→85% 交叉过渡；容器自带一道随形移动的高光。
5. **衬底**：整段转场铺一层从"旧页面底色"渐变到"新页面底色"的衬底——15d 的黑/白闪就是缺这一层（`#main` 不可见时会露出 body 底色）。
6. **返回**：新增 `mode:'reverse'`（360ms），从 `.quiz-card` 或预览完成页反向回到 `.d-stage`；`backToToday()` 统一入口。
7. **行级入口**：`resolveFrom` 增加 `.d-row`，行内"开始"也能从那一行起飞（15d 只允许 ≥40px 高的容器，行内按钮被静默降级为直接切页）。

**实测（`__morphTrace`）**：

| | 15d | 15e 进入 | 15e 返回 |
|---|---|---|---|
| 时长 | 620ms | 440ms（trace 480ms） | 360ms（trace 381ms） |
| 25% 时间完成位移 | 80.6% | 35.2% | 29.0% |
| 50% | — | 66.6% | 61.0% |
| 75% | — | 90.4% | 91.0% |
| 90% | 98.3% | 99.0% | 98.5% |
| 新旧内容同帧可读 | 有（412ms） | **无**（`overlap: null`） | **无** |
| 几何回退 | — | 0 | 0 |

## P3 主 CTA

**症状**：舞台"开始今天的训练"（钛白实心）与行内"开始"（琥珀实心）同时争夺主操作。

**改动**：
- 主行动唯一化：舞台按钮是**唯一实心**主 CTA（深色主题钛白金属、浅色主题墨块）。
- 行内"开始"改为次级：透明底 + 细描边 + 次色文字；琥珀只保留为"当前项"的状态色（左侧圆点、时间带高亮段），不再做按钮填充。
- 任务直接启动能力保留（点行内的"开始"仍然直接进入该项），只是视觉降级。

**证据**：截图 `today-dark.png` / `today-light.png`；行内按钮计算样式为描边次级态。
