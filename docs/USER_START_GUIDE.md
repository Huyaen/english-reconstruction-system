# 词间 · 使用与启动指南（v1.0.0）

## 一、怎么打开

- 双击桌面上的 **「词间」** 快捷方式，或项目目录里的 **`启动词间.cmd`**。
- 它会自己起一个本地服务，然后打开浏览器到 `http://localhost:4173`。
- 关闭页面不会丢数据；下次再打开还在。
- 想彻底关掉后台服务：双击 **`停止词间.cmd`**。

> 必须用 `localhost:4173` 这个地址。换成别的端口或 `127.0.0.1`，浏览器会当成另一个网站，看到的是空库——不是数据丢了。

## 二、第一次打开会发生什么

1. 浏览器会把这个地址当成一个独立的小应用，数据存在浏览器本地（IndexedDB），**不上传任何服务器**。
2. 如果你之前用过旧版本，第一次打开会自动把旧库升级到当前版本（v7）。升级前建议先做一次备份（见第三节）。
3. 想用 AI 出题/反馈：设置 → 填 endpoint、模型名、密钥 → 勾选「记住密钥」才会保存到本地。不填也能用全部本地功能。

## 三、备份与恢复（重要）

**备份**：设置 → 「导出全部学习数据」→ 得到一个 `词间完整备份-YYYY-MM-DD.json`。

- 备份里**不包含** AI 密钥（安全考虑），恢复后要重新填一次。
- 建议固定放在 `D:\英语重构训练\词间备份\`，文件名带日期。

**恢复**：设置 → 选择备份文件 → 预览计数 → 确认。恢复会**覆盖当前库**，所以恢复前先导出一份现有的。

更细的说明见 `docs/BACKUP_AND_RESTORE.md`。

## 四、数据在哪、怎么保护

- 位置：Edge（或你默认浏览器）的本地存储，站点 `http://localhost:4173`。
- 清理浏览器「Cookie 和网站数据」会把学习数据一起清掉——清理前先导出备份。
- 换浏览器 / 换电脑：在新环境打开应用后，用备份文件恢复即可。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 双击后提示「端口 4173 被别的程序占用」 | 先跑「停止词间.cmd」；不行就重启电脑或改掉占用 4173 的程序。**不要**改成别的端口启动，那样会看不到原来的数据。 |
| 打开是白屏 | 等服务起来（脚本会等最多 40 秒）；还不行看项目目录的 `cijian-server.log.err`。 |
| 数据「不见了」 | 99% 是地址不是 `localhost:4173`（换了端口/主机名）。用启动器重新打开。 |
| AI 一直失败 | 设置里检查 endpoint / 模型名 / 密钥；密钥不会被备份带走，恢复后要重填。 |
| 页面看起来是旧的 | 关掉页面重开；本地服务会带版本号缓存，正常刷新即可拿到新版本。 |

## 六、隐私

- 所有学习记录只存在本机浏览器；只有你主动点 AI 功能时，才会把当次需要的文本发给你配置的那个服务。
- 备份文件是你自己的数据，别随手发到公开地方。
