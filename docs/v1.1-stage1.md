# v1.1 第一阶段实施与验收

需求来源：本次用户完整任务书。只做自动备份与独立拼写练习。

1. 自动备份：复用完整 JSON，清除两处 AI Key；授权目录句柄存 meta，不进入备份。每次写前查询权限，只在点击时请求授权。唯一新文件、关闭后重读逐字及结构校验，成功后再清理自有清单中超过 14 份的备份。串行任务并持久化完成事件去重。验证：模拟权限、故障、并发、恢复；隔离 Edge 实际目录文件。
2. 拼写：新增独立 v8 store，只记录拼写尝试；复用范围与词条队列，不调用 answer 或证据调度更新。相似释义题排除，大小写保留，合并大小写词排除。先做 v7→v8 和旧备份测试，再实现页面。验证：判题、重试、辅助标记、无旧调度变化、4716 条合成规模。
3. 每项通过针对测试及构建后独立提交，再全量回归。真实浏览器仅新 profile、新端口；不读取或修改日常 IndexedDB。

边界：关闭浏览器、断电或权限失效不能保证会话已写入磁盘；成功时间只代表文件关闭及重读校验成功，不等于物理磁盘抗断电保证。新版数据库升级后旧程序不能直接打开；回退先由新版导出，拼写证据需保留新版备份。

验收：开发前 438/438；自动备份提交 320c3a9；两功能最终全量 455/455，TypeScript、生产构建与测试构建通过。隔离 Edge 128 / 127.0.0.1:4186 已验证真实系统目录授权、磁盘写入、恢复、14份轮替、非本程序清单文件保留、拼写输入与旧选择题快捷键。权限丢失、写入失败、写后损坏、元数据失败以可控故障测试验证；没有制造真实断电或磁盘故障。

新版本使用：沿用原有「启动词间.cmd」和 localhost:4173 地址。设置→自动备份→选择目录；原有完整 JSON 导出/恢复入口保留。首页「自己再练一轮」中选择词书和数量，再点「拼写练习 · 看中文写英文」。按 Enter 提交；提交或主动查看后才出现标准答案。错误可加入本轮重练；结果页可继续辅助轮。首次独立正确率排除辅助和重练。每次提交单独落盘；中途退出保留已提交证据，但本阶段不提供刷新后续接拼写队列。

拼写规则：保留大小写、词序、连字符及其他标点；仅合并首尾/连续空白和弯撇号。共享/重叠释义、合并词条、题面泄漏答案等保守排除。当前输入目标限英文字母、空白、撇号和连字符；复杂缩写或数字词条会排除，不会修改原词书。规则只覆盖词库已有释义，不能保证识别所有语义同义词。

兼容：v7→v8仅新增 spellingAttempts 及索引；4716条合成规模夹具逐ID核对不变。真实上海词书和学习数据库未访问，因此不把合成测试当作该真实数据库的直接验收。v1至v7备份安全识别并补空拼写证据；v8完整备份包含拼写证据。API Key两处清除，目录授权只在本机meta保存。导词/删词/恢复不把其他设备目录授权带入。删除词书同时删除相关拼写证据。

独立复核修复：规范化题面泄漏、后台重绘丢失拼写输入、句子证据保存失败却触发备份，均有先失败后通过的回归测试。句子存储失败时沿用原有提示，并跳过该轮自动备份；没有顺带重构句子证据系统。

保留范围：只清理当前设备目录清单中已校验且所有权标记一致的自动备份。更换目录、重新选择目录或浏览器元数据丢失后，不追认和删除旧登记批次文件；磁盘上可能因此超过14份。清理失败也保留多余文件并提示，优先保留有效备份。
