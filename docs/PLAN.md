# 实施方案
目标：完成需求中的 MVP，保留可恢复的源码、测试、文档和构建产物。
选择纯 TypeScript 模块 + IndexedDB，避免引入服务端和账号。React 对本项目并非必要；全栈方案会增加本地部署负担。
界面：墨蓝侧栏、蓝色操作按钮、清晰数字、紧凑白色工作区；深色与手机布局。首次打开真实空状态，提供词书导入入口，无预填学习数据。
模块顺序及验收：
1. types.ts / core.ts：类型、熟练度、优先级、独立调度、候选选项。测试边界、双向证据、过早刷题不延长长期间隔、同义排除。
2. import.ts / db.ts：TXT CSV JSON XLSX，规范化去重；IndexedDB事务，逐题记录与队列原子保存；备份先验证后替换。测试损坏备份不影响旧数据。
3. app.ts / quiz.ts / style.css：导入预览、筛选范围、四种训练、键盘及超时、恢复中断训练。防止连按重复提交。
4. stats.ts / ai.ts：真实记录统计、7/30天趋势、方向差异、词详情、AI自定义API请求和历史。
5. 浏览器验证：刷新、关闭重开、备份恢复、键鼠、手机、1000题性能；构建和打包。
每个模块完成即更新 CHECKPOINT.md / TODO.md / DEVELOPMENT_LOG.md，提交Git并将完整源码压缩包保存为同一交付文件的新版本。
最终AI真实服务验证需要用户自己的Endpoint/Key/Model；开发测试只验证协议与失败处理，不能冒充真实供应商验证。
