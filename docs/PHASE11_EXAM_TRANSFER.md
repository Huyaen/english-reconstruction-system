# Phase 11 — 上海高考英语迁移与统一测评

状态：**已交付**（2026-10-23）
范围：考试规格与题库、统一测评引擎、错因归因、迁移复测、周测、学校考试记录、考试域诊断指标、每日计划接入。

## 0. 这份功能不做什么

- 不预测高考分数，不生成“英语总分”，不把练习分数映射成 150 分制。
- 不把 AI 生成材料当官方真题；不复制商业教辅。
- 不把一次正确、一次周测、一次学校分数写成“掌握”。
- 不假设 2028 规则。2028 规格里的未知字段保持 `null` / `provisional`，界面显示“待确认”。

## 2. 规格版本化

`ExamSpecification` 记录：地区、考试类别、适用年份、状态、发布机构、来源引用（URL/标题/机构/发布日期/适用年份/来源类型/置信度/核验时间）、总分/笔试/听说/时长、分节、题型、评分规则、备注。

`validateSpecification()` 拦截：

- 笔试 + 听说 ≠ 总分；
- 分节合计 ≠ 总分（所有分节分值已知时）；
- `official_confirmed` 没有官方来源或发布日期；
- 来源 URL 非法；
- 未来年份“官方确认”给出警告。

考试类别分开存储（`ExamCategory`），合格考记录不能混进高考统计；学校考试记录是自报，单独 `examLogs`。

## 3. 题目契约

`AssessmentItem` 必填：考试类别/年份、用途（考试/周测）、section、题型、题干、选项、答案、答案依据、解析、分值、预计时间、难度与难度依据、目标能力/词汇/语法、来源、许可证、provenance、verifiedStatus、创建时间。

入库前 `validateBank()` 校验：

- 选择题答案必须是有效选项 ID，选项不重复；
- 客观题分值 > 0；
- AI 生成题不得标 `verified`，不得冒充 `official_sample`；
- 用户材料不得无依据标已验证；
- 材料引用必须存在；
- 开放题没有 rubric 给警告，不能自动评分；
- 听力无音频给警告，并在“新题”列表中排除，避免“假装听过”。

内置题库全部 `provenance='authored'`、`license='project-authored'`、`examCategory='other'`。它们是**项目自编迁移材料**，不声称对应任何年份真题。题量不足以覆盖官方结构时，界面显示 0 题，不补假题。

## 4. 统一测评引擎

模式：`skill_practice`、`mixed_practice`、`timed_practice`、`review`、`transfer_retest`、`weekly_assessment`、`imported_log`。

状态机：

```
created → active ⇄ paused → submitted → reviewed → completed
                                  ↘ abandoned
```

- 答案自动保存（显式保存/切题/提交时写入）；会话快照保存题目数组，刷新不换题。
- 每次写入 revision +1；存储层比较 revision，冲突返回 `stale`，不静默覆盖。
- 重复提交/复盘/完成返回 `noop`，revision 不变。
- 未答完：`score=null`、`scoreStatus='partial'`，不拿已答题凑总分。
- 含开放题：最多 `partial`，只报客观分；`verified_objective` 仅当全部题目有可靠客观答案且全部作答。
- 开放题、翻译、概要、写作、口语不自动评分；显示 rubric 与“不可评分/部分评分”。
- 听力无音频：不生成任务；不得用占位音频或伪造原文。

评分状态：`verified_objective` / `rubric_reviewed` / `ai_estimated` / `self_reported` / `unavailable` / `partial`。UI 每次都显示评分来源，不用颜色暗示“官方”。

## 5. 错因归因

六类：`vocabulary`、`structure`、`logic`、`evidence`、`overthinking`、`time_pressure`，另有 `uncertain`。二级：词义/搭配/从句关系/指代/干扰项/误读/证据不足/时间策略/粗心/过度概括/其他。

归因优先级：

1. 用户自报（`userReported`，置信度 `medium`，不称已验证）；
2. 选项级 distractor 证据（作者写的干扰项分析，`medium`）；
3. 题目目标能力的弱推断（`low`）；
4. 无证据 → `uncertain`，绝不硬判“阅读差”。

每条错因保存：题目、类别/二级、置信度、解释、证据引用、其他可能、干预建议、是否用户修正。用户可在结果页修正类别，修正后标 `correctedByUser`，保留原证据链。

干预只给方向（回词汇/句子/阅读/证据定位/限时），不自动改学习权重、不自动加掌握度。

## 6. 迁移复测

- 只用**未做过**的新题；已用题 ID 永久排除，同一题不重复冒充迁移。
- 按错因选同能力新题（词汇/语法/阅读逻辑/证据定位）；题库不足时明确拒绝，不降级为重复题。
- 会话标 `transfer_retest`，来源 `transfer-new-item`；帮助次数记录；一次通过只产生考试证据，不直接改 `Word` 掌握度。
- 迁移测试仍走同一测评引擎，不建第二套评分。

## 7. 周测（15–25 分钟）

五个部分，缺什么就 `unavailable`：

1. **延迟词汇**：从真实词库选已复习、释义互不相同的词，生成 4 选 1；少于 4 个不同释义时不生成。
2. **未见句子**：题库中未用过的句法题；都做过就明确“需要新题”。
3. **真实阅读**：只用**未读过**的 `Passage`，要求写主旨 + 引用依据；不伪造选择题，不重复已读文章。
4. **独立表达**：2–4 句英语，自写；不评作文分。
5. **翻译依赖自评**：仅趋势自评，不是能力分数。

总时长按题目预计时间求和，超出 25 分钟时优先移除开放阅读/表达项并记录原因；少于 3 项不生成完整周测。报告保存客观题正确数/总数、完成部分、不可用部分、自评依赖，并声明“只描述这一次表现；自评不是能力证明”。

周测会话是固定快照；刷新/重开不重新出题。

## 8. 每日计划接入

- 默认关闭（`settings.exam.planEnabled=false`）。
- 用户显式开启、有未做新题、剩余预算 ≥ 6 分钟时，最多 1 题、5–10 分钟、优先级 32、`flexible=true`、`critical=false`。
- 不挤占关键记忆任务与 closing；装不下就记录 `exam-deferred-budget`，不硬塞。
- 题目做过即不再进入计划，避免重复题刷量。

## 9. 诊断指标

新增 `exam` 域（不与词汇/阅读/产出合并成总分）：

| 指标 | 分子/分母 | 质量 |
| --- | --- | --- |
| 考试客观题正确率 | 正确客观题 / 已提交客观题 | verified |
| 无辅助完成占比 | helpUsed=0 的完成会话 / 完成会话 | task-behavior |
| 完成迁移复测次数 | 完成的 transfer_retest | task-behavior |
| 接近时限完成占比 | 用时 ≥ 90% 时限 / 计时会话 | task-behavior |
| 错因不确定占比 | uncertain / 全部错因 | task-behavior |
| 官方分数预测 | 不可计算（`not-applicable`） | none |

无样本 → `value=null` + `insufficient`，不用 0；所有比率带分母；官方分预测明确标“不提供”。

## 10. 数据模型（DB v7，additive）

新 store：`examSpecifications`、`examMaterials`、`examItems`、`examSessions`、`examLogs`。旧 store 不改、不迁移、不重写；`DB_VERSION=7`；备份白名单自动跟随；`validateBackup` 对 v1–v7 兼容。

内置规格/材料/题目按稳定 ID 幂等覆盖（内容不可变）；不覆盖用户导入的材料/记录。会话/日志按 ID 持久化；周测快照存在会话内。

## 11. 验收（AC）

- AC1 规格有来源、状态、年份；2028 不冒充确定。
- AC2 分值/时长一致性与版本化校验。
- AC3 题目来源/答案依据/审核状态显式；伪造答案被拒。
- AC4 统一测评状态机、自动保存、刷新恢复、revision 冲突。
- AC5 未答完不算总分；开放题不自动评分；评分来源可见。
- AC6 错因六类 + 二级 + 置信度 + 其他可能 + 用户修正。
- AC7 迁移只用新题；无新题拒绝。
- AC8 周测五部分；缺材料明确不可用；15–25 分钟；快照固定。
- AC9 每日计划默认关闭；开启后短时低优先级；不挤占关键任务。
- AC10 考试域指标带分母、可评估性、证据质量；无官方总分预测。
- AC11 DB v7 additive；备份往返；旧备份可读。
- AC12 生产构建摇树移除 `__examTest`。
- AC13 真实浏览器 smoke 全绿（16/16）。
- AC14 回归 phase3–phase10 全绿。

## 12. 边界与后续

- 题库是项目自编，不是官方真题；不能据此推断官方难度或分值分布。
- 2028 规则未公布，任何“2028 确定 115+35”的说法都是错误的。
- 听力无音频、口语不自动评分；相关部分显示 unavailable。
- 学校分数只作自报事实，不参与掌握度或预测。
- 周测的阅读只要求主旨+依据，不做客观选择题；这是为了不伪造题目。
- 诊断中的考试指标只描述考试行为，不证明迁移完成；迁移需要多次、不同语境的新题证据。
