## 实际功能

- 单词预览、词条详情、已揭晓的选择题错误反馈、拼写与原句反馈提供统一喇叭和停止按钮。未揭晓的练习题不提供目标发音。输入框和发音按钮不触发全局答题快捷键。换页、换题、关闭详情和页面隐藏会清理本应用拥有的语音。
- 设置中的「英文发音」可选 en-US / en-GB。优先已安装英语语音，再考虑指定口音、自然语音名称和系统默认；只有联网音源时使用浏览器提供的联网英语语音，明确显示实际口音/服务。没有英语、加载异常、播放错误或超时均提示失败。名称不能证明音质；原生语音不能保证专业词典级音质或多词性发音。
- 薄弱词页面被动展示最多3个「换个方法练」建议，详情说明证据。可自选拼写、已有真实原句练习，或关闭该词提示7天。混淆对照只显示已有词条释义，不生成解释或例句。无可靠原句时入口不可用。
- 从已显示答案的词条详情开始的针对性拼写/原句练习，明确标记为辅助巩固，不能计入首次独立正确。提示、关闭和发音不改变 FSRS、到期时间或 ReviewRecord。

## 证据门槛

只看近60天、非未来的记录，按记录ID和每词每会话首次作答去重，再排除辅助/重试。

- 选择题至少6个独立会话、跨3个本地日期、至少48小时间隔。最近3次均错，或已有遗忘状态且曾成功后至少3天再次失败，才说明相应证据。
- 混淆需要上述样本门槛，并且实际跨至少2天错选同一现存词至少3次，以及已有混淆计数至少3。
- 拼写/原句分别至少4个非辅助非重试轮次，跨2天且至少24小时，最近4次至少3次错。原句只接收非AI已保存阅读来源。仅选择题有足够证据且至少4/6答对时才提示识别与拼写差距。

## 兼容与限制

DB版本仍9，无store变更/迁移；仅新增可选设置 `pronunciationLocale` 和 `stubbornSnoozedUntil`，缺失时安全默认。现有完整备份/恢复携带这两项并校验类型，API Key仍不导出。旧v9数据直接兼容；本轮没有使用旧程序打开任何真实库，已有DB9不能由DB8旧程序直接打开的限制继续存在。所有真实备份、完整词库、学习记录、测试密钥、系统安装日志均在仓库外。

本机最初只有中文本地语音，原生联网英语实际报 `synthesis-failed`。经用户明确授权，安装微软en-US TextToSpeech（Basic已安装）；最终Installed，无需重启，不改显示语言。重启隔离Edge后识别到David/Mark/Zira。没有本地en-GB，因此选择英式时可回退本地美式并明确显示；不自动下载安装其他语音，不绕过系统授权。

## 复跑

先使用测试构建在4206端口启动，使用全新隔离Edge profile、9406调试端口打开 `?test=1`。脚本只连接该调试端口和该origin，要求测试钩子。准备仓库外的无密钥v9完整备份（实际4716词）与 `alice-reading.txt` 原文，然后设置：

```powershell
$env:CIJIAN_E2E_DIR = '你的隔离夹具目录'
$env:CIJIAN_E2E_OUTPUT = '你的测试报告目录'
$env:CIJIAN_E2E_REAL_BACKUP = '你的隔离完整备份.json'
node --import tsx scripts/v1.3-e2e.mjs pronunciation
node --import tsx scripts/v1.3-e2e.mjs stubborn
node --import tsx scripts/v1.3-e2e.mjs choice-backup
```

脚本会覆盖隔离测试库，不得把9406指向日常profile。`choice-backup`先通过原预览流程使新词可复习；原始阅读材料不得换成AI生成句子冒充原文。截图与完整日志保存到外部输出目录。
