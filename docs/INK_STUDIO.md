# 墨序全站设计蓝图

桌面导航常驻。主入口依次为今天、词库、阅读、写作练习、学习报告。更多中保留其余训练、学情和配置。移动端沿用同一顺序，折叠菜单保留当前路径的选中提示。任务内首先提供当前内容、进度和退出。

| 页面 | 首要信息与动作 | 相邻路径和保留契约 |
| --- | --- | --- |
| 今天 | 当前任务、开始或继续、安排时间 | 计划、训练、学习记录；任务理由来自当前计划 |
| 词库 | 当前词书、搜索筛选、导入 | 独立词书进度及词条详情；同名数据不合并 |
| 需巩固 | 薄弱项目与练习入口 | 复习、当前词书；保留真实选词算法 |
| 单词练习 | 字词、音标、答案、即时反馈 | 预览、回忆、拼写、暂停、结算、返回计划 |
| 句子 | 来源、原句、步骤和选择 | 拆句、回看、语法；证据可信度不变 |
| 阅读 | 正文优先、词句标记与辅助 | 导入、首读、精读、解释、恢复；来源可追溯 |
| 输入 | 材料与导入、续学 | 送入阅读或表达流程；保留记录 |
| 写作练习 | 草稿、任务意图、对应反馈 | 保存、修订、续写；独立与辅助记录分开 |
| 语法 | 概念、关系、证据 | 概念详情与拆句；保留原分类和可信度 |
| 学习单元 | 推荐顺序与任务执行 | 阅读、用词和输出；保留状态续接 |
| 学情诊断 | 有证据的变化、证据限制 | 后续推荐，证据不足时明确写出 |
| 考试 | 任务类型、证据、进度 | 过程反馈、暂停恢复、完成记录 |
| 学习报告 | 作答趋势、负担和可比数据 | 今日与学情；不补造分母或成绩 |
| AI 辅助 | 使用入口和证据来源 | 定向练习、生成、复盘及设置；模型意见与客观作答分开 |
| 设置 | 学习偏好、AI 连接和用量、备份状态 | 保存原配置、失败可恢复，每项状态以真实记录为准 |

共用的标题、状态、表单、键盘焦点、提示、弹窗和纸面由语义 token 和外壳控制。独立运行态沿用已有状态流，窄屏优先作答和正文。主要依据来自编辑式窄正文、目录式导航和稳定的工作台分区。
