# Phase 15c · Today 两套原型（A / B）对照说明

> 本轮不改选型，只提供两个**真正不同的方向**供比较。
> 默认路径（不带 `?proto`）仍然是 15b 界面，业务与数据链路一行未动。

## 0. 一句话

- **A · Obsidian Instrument**：把今天做成一台**非对称的仪表台**——一块黑曜石面板、一支铂金游标尺、一个分钟构图盘、一条竖向序列轨。
- **B · Atmospheric Studio**：把今天做成**一个舞台**——体积光从上方落下，主卡落在光池上，读数条与时间带以不同高度叠在台前。

两者共享同一套业务动作（`bindPlan()` 的数据属性完全相同），但 DOM 结构、构图、材质语言、动效节奏、时间表达方式都不同。

## 1. 共同保留 / 共同推翻

| 保留 | 推翻 |
|---|---|
| 15a 已验证的排版尺度、任务层级、`data-task-*` 契约、`#start-today` / `#plan-create` 等入口 | 15b 的“单卡 + 卡片清单 + 暖色点缀”作为默认构图 |
| 同步渲染合同（任何动画都不延迟 DOM 写入） | 只靠边框和阴影区分层级 |
| 阅读页 19px / 1.72 / 66ch 的阅读度量 | 把今天的信息压成一张大卡再配一串重复卡片 |

## 2. A 与 B 到底差在哪

| 维度 | A · Obsidian Instrument | B · Atmospheric Studio |
|---|---|---|
| 构图 | 非对称双栏：仪表台 1.42fr / 序列轨 0.58fr，两者等高 | 单列居中舞台：主卡 → 读数条 → 时间带，宽度 780 / 1000 递减 |
| 光源 | 单一左上 45° 冷光，只擦亮面板上缘与数字 | 顶部体积光锥 + 地面暖色光池，卡片离地 |
| 主材质 | 黑曜石面板 + 铂金刻度 + 阳极金属主按钮 | 磨砂玻璃 + 丝绒面 + 暖白胶囊主按钮 |
| 时间的表达 | 竖排：绝对分钟数（68）+ 游标尺（0–150）+ 刻度环（已排/未排） | 横排：时间带（段宽=分钟数，01–09 与列表同序号）+ 读数条 |
| 任务序列 | 一条贯穿的蚀刻轨，9 段等距；当前段有琥珀侧光带 | 3 段“接下来” + `还有 6 项` 展开；每段与时间带同号 |
| 导航语言 | 直角激活条 + 琥珀侧线，像仪器面板上的档位 | 保持柔和胶囊，只在不抢舞台的前提下降低对比 |
| 动效 | 面板 520ms 掀开 + 顶部 1px 扫光；序列 70ms 交错 | 舞台 700ms 浮起 + 玻璃层 90/150ms 依次落位；光锥常驻 |
| 移动端 | 仪表压成单列，时钟仍最大，动作按钮变大到 12px/44px 高 | 先“还剩多久 + 现在做什么 + 一个开始”，时间带缩到 3 段 + 展开 |
| 最像 | 录音室调音台 / 仪表盘 | 剧院舞台 / 影院开场 |

## 3. 与参考图的逐项对照

参考来自本地 `docs/reference/`（第三方图像，**不随仓库分发**，仅记录页码与要素）。

| 参考要素 | A 的对应 | B 的对应 | 证据 |
|---|---|---|---|
| 左上定向主光、暗部在右下（手册 p3，Raycast） | 面板 `radial-gradient(240px 130px at 8% -8%)` + 右下 55% 压暗；游标尺与按钮的高光只在上缘 | 光锥 `top:-18px`、`rotateX(6deg)`、`blur(34px)`，落点偏上；卡片主体仍在暗部 | `a/today-dark-1920x1080.png`、`b/today-dark-1920x1080.png` |
| 金属只用来做“边缘”，不铺满（p3） | 金属仅出现在主按钮与游标尺的针/亮线，正文区零金属 | 金属退到 0，改用玻璃与暖光；白块只保留当前时间段的标签 | 同上 |
| 深空间 + 单色 + 一处暖色（p4，Endel） | 黑曜石底 + 铂金，暖色只给“当前/关键记忆” | 深蓝黑底 + 冷光锥 + 一抹暖光池 | `a/today-dark-390x844.png`、`b/today-dark-390x844.png` |
| 信息组织优先、任务即主角（p2，Things） | 序列轨的第一行永远是“当前”，其余按序退后 | “接下来”只露 3 项，其余折叠，避免一次看 9 条 | `a/today-*`、`b/today-*` |
| 专注阅读、正文最大化（p2，iA Writer） | Reading 保留 66ch / 1.74，外壳材质化 | 同 | `*/reading-dark-1920x1080.png` |
| 柔和材质、低对比不刺眼（p2，Bear） | 浅色走“博物馆冷白 + 硬边细线”，不靠弥散阴影 | 浅色走“晨光摄影棚”，允许一层体积光 | `a/today-light-1920x1080.png`、`b/today-light-1920x1080.png` |
| 8 类动效（p15） | 扫光 / 交错 / 指针高光 / 按压 / 共享元素 | 浮起 / 层叠落位 / 时间带抬升 / 主题过渡 | `*/recording/today-*.mp4` |

**版权边界**：所有数值、渐变、构图均为本轮原创；参考图只用于比对光位与层级，未把任何图像或版式复制进代码或产物。

## 4. 九类交互的证据

| 交互 | 证据 |
|---|---|
| 页面进入 | `today-*.mp4` 0–2s：A 面板掀开+顶部扫光；B 舞台浮起+玻璃层落位 |
| 主按钮悬停 | 2–4s：金属/玻璃高光移动，`transform` 仅 1–2px |
| 主按钮按下 | 5–6s：真实 `mousePressed` 保持 280ms，按钮内陷，随后进入训练 |
| 任务卡悬停 / 展开 | 3–5s：A 行抬升 + 侧光；B 打开 `还有 6 项`，9 段与列表同号 |
| 共享元素转场 | 6–8s：进入训练会话（真实页面，非 mock） |
| 返回 | 8–10s：回到 Today，反方向重建 |
| 主题切换 | 10–12s：真实点击 `#theme`，材质重新受光 |
| reduced-motion 降级 | `reduced-motion.json` + `reduced-motion-{dark,light}.png`：`animation: none`、`transition: 0s`（两套 × 两主题实测） |
| 无横向溢出 | 390/360 视口 `overflowX: false`（见 capture manifest 与 reduced-motion.json） |

共享元素转场仍是 15a 的安全实现：**克隆层 FLIP**，真实 DOM 同步更新，动画载体是 `position: fixed` 的临时元素，420ms 后自删——所以 `phase12-full-smoke` 的同步断言才可能继续通过。

## 5. Reading

- 工具栏：上缘 1px 窄光 + 下缘 3px 暗边，读作一条压条；元信息从“·”串改成**分隔线读数条**；右侧新增段落刻度（读过的实心、当前段更长）。
- 正文：19px / 1.72 / 66ch 不动；纸面边界收紧，外壳与右栏退后。
- 辅助面板：分组 + 细线 + 更小的控件；不出现体积光。

## 6. 性能（同一 headless Edge，1440×900，同一指针/滚动负载）

| 运行 | 平均帧时间 | p95 | >20ms 掉帧 | long task | style 重算 | layout | DOM 节点 |
|---|---|---|---|---|---|---|---|
| 15b | 3.85ms | 3.9ms | 0% | 0 / 0ms | 615 | 1 | 254 |
| A | 3.86ms | 3.9ms | 0% | 0 / 0ms | 220 | 17 | 290 |
| B | 3.95ms | 3.9ms | 0.1% | 0 / 0ms | 40 | 0 | 253 |

结论：没有可测的掉帧或长任务差异；A 少了 2/3 的 style 重算（更多的合成层、更少的重排），B 几乎不触发重算（玻璃层在合成阶段完成）。A 的 17 次 layout 来自指针高光写入 `--rx/--ry` 后的一次布局读取，未造成掉帧。

## 7. 可访问性（本轮新增精确审计）

旧探针在有渐变背景的元素上采样会失真（读到 1.01/1.9 这类假值）。新增 `scripts/phase15c-contrast.mjs`：只算**真实前景色 vs 最近一层不透明背景色**，同一套 WCAG 公式。

| 组合 | 检查元素 | 违规 |
|---|---|---|
| A 深色 1920 / 390 | 226 | 0 |
| A 浅色 1920 / 390 | 226 | 0 |
| B 深色 1920 / 390 | 189 | 0 |
| B 浅色 1920 / 390 | 189 | 0 |

过程中真修掉 4 处：序列“开始”按钮（3.78）、B 的“接下来”标签（3.25）、游标尺读数、以及渐变按钮缺真实 `background-color`（强制色彩/打印下会变黑字黑底）。

## 8. 还没做的事（明确边界）

- 其余 12 个页面**未**套用任一原型：等选定方向后再统一。
- 两套原型都还没做键盘全链路走查与读屏实测（只有对比度与可访问名称）。
- 原型未做 `prefers-contrast: more` 变体。
- 截图与录屏不入库（`screenshots/` 已在 `.git/info/exclude` 内），脚本可完整复现。
