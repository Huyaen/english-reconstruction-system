# 词间 v1.4 候选版验收说明

## 写作练习 · 表达错误复盘

可选最近 7、14、30 个本地自然日，含今天。任务以创建日归窗，后续修订或重评不会移到新窗口。按提交 ID、计划任务和同题同稿去重。同一处 AI 建议按原文位置合并，优先保留重点列表的分类。不同任务使用同一题型仍可产生独立样本。

通过质量门的 AI、可核对的本地形式检查、低置信度启发式提示和自述分别标示。只有关联到该初稿的已通过质量门生成记录才能进入 AI 分母。缺少、失败和无效的反馈记为 AI 无法评估，模拟反馈单独标记并排除。AI 检查不能代替人工批改。

同来源至少检查过 3 个独立任务，同类问题至少出现在其中 2 个任务时才推荐复看，最多两类。对应语法点在句库确有训练内容时可进入现有练习，其余可对照原稿与建议再写一句。

## 学习报告 · 实测保持率

以该词最早合格作答近似首次学习日期，按本机日历日计算。D1 取第 1 天，D7 取第 6–8 天，D30 取第 27–33 天。各题型各窗口每词只取首次合格结果，最少需要 5 个独立词才显示比例。已进入窗口却没作答的词只计覆盖范围。

两种方向的选择题都属于识别。历史选择题记录缺少辅助标志，无法追溯提示使用情况。拼写和已保存阅读原句分账，只取明确非辅助、非重试的作答。主动选择“不认识”计未答对，超时未作答不计。指标只描述实际被选中复习的词，三个模式不合并。

新版实时指标查看全历史，与报告顶部最近天数的其他指标分开。旧版从首次记录按固定 24 小时段累计作答，仍在历史对照中可见。既有报告、诊断建议和计划沿用旧口径。

## 复跑与兼容

`npm test`、`npm run build` 和 `npm run build:test` 分别运行全量测试、生产构建与带现有验收入口的测试构建。测试夹具覆盖日历边界、夏令时、重复与冲突 ID、历史引用失效、错误反馈来源，以及 4,716 词和 51,876 条合成作答。

`scripts/v1.4-e2e.mjs` 使用独立 Edge 配置、调试端口 9414 和 `http://127.0.0.1:4214/?test=1`。在隔离服务目录运行 `node server.mjs --dir=dist-test --port=4214`。`CIJIAN_E2E_REAL_BACKUP` 指向仓库外的去密钥 DB9 备份，`CIJIAN_E2E_OUTPUT` 指定证据目录，随后执行 `node --import tsx scripts/v1.4-e2e.mjs`。脚本先核验真实词条和数据域，再用合成作答与反馈测试两块 UI，最后恢复隔离基线。截图有合成数据标记。

数据库版本仍为 v9。新增指标实时计算，既有 JSON、自动备份授权和学习记录继续使用原结构。可切回 v1.3.0 应用代码读取原有 DB9。发布范围为候选分支和草稿 PR。
