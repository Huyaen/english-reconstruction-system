## 四、按业务语义保留、但补了说明的两项

1. **优先级字母 S/A/B/C/D**：保留字母（中文等级会把 6 列表格拉宽，且字母与既有排序桶一一对应），但必须同时给出表头、单元格说明和图例（已做）。属于「保留 + 解释」，不是保留问题。
2. **设置页技术字段**：`JSON Mode / JSON Schema / CORS / token` 是协议名与计费单位，翻译反而让用户在服务商文档里对不上号。处理方式：保留原名 + 同句给人话解释（`token 是服务商计费的单位，1 个 token 大约是半个英文单词`；`浏览器直连还要求服务商允许跨域访问`）。`Endpoint` 一词在设置页统一为「服务地址」。

## 七、新增防回归机制

**为什么上一轮是 0 命中却漏了一片**：`phase16-forbidden-scan.mjs` 只匹配固定的英文术语白名单（Preview/Recall/FSRS…），小写枚举、阶段号、原因代码、英文标题不在白名单里，所以扫不出来。

本轮换成按**问题形态**检测：

| 文件 | 作用 |
| --- | --- |
| `scripts/lib/copyLint.mjs` | 检测内核（纯函数）：kebab 原因码 / snake 枚举 / `phase+数字` / 原始状态值 / 英文标题 / 假精度 / 样本比较式；含豁免表与逐行 `copy-lint:allow <rule>` |

| 术语 | 保留理由 |
