# 移动端、键盘与可访问性（Phase 13–14）

## 已验证

`scripts/phase13-smoke.mjs` 在 **390×844** 视口下检查：

- `home / settings / reading / input / output / exam` 没有横向溢出；
- 主要按钮都有可访问名称（文字或 `aria-label`），`unnamed=0`；
- 深色主题可切换并生效，可切回浅色；
- Tab 键能移动键盘焦点（焦点落在导航按钮上）；
- 页面无未捕获 JavaScript 错误。

Phase 14 新增设置页「数据地址」面板后，重新跑 Phase 13：**20/20**，390px 仍无横向溢出。

## 未验证

- **真实手机**：没有 iPhone Safari、Android Chrome 实机；390px 只是 Edge 视口模拟。
- **触控与软键盘**：没有测真实手指点击、长按、软键盘遮挡输入框。
- **屏幕阅读器**：没有 NVDA / VoiceOver / TalkBack 实测；可访问名称不等于完整朗读体验。
- **200% 缩放 / 高对比度 / 减少动画**：没有逐项自动化。
- **横屏、平板、折叠屏**：没有覆盖。

因此本阶段只能声明“在 390px 无头 Edge 下无明显布局溢出、按钮有名称、键盘可聚焦”，不能声明“移动端全面通过”。
