# Phase 8 补充规格 — Dynamic Interest Profile（动态兴趣画像）

> 状态：**长期规格已冻结**；兴趣画像本体已实现并验收（2026-10-20）。
> 适用范围：所有「推荐 / 排序 / 主题建议」入口，从 Phase 7 的 Mini Unit 主题推荐开始生效。
> 一句话：**兴趣只决定先看什么，不决定你能学什么，也不决定你学得怎么样。**

## 1. 为什么不是「固定分类」

固定分类或永久标签会制造三种错误：

1. **白名单效应**：用户想读的东西不在分类里，系统就推荐不了——能力被分类限制。
2. **永久画像**：一次点击被当作长期偏好，之后反复推同一类内容。
3. **概念污染**：把「喜欢科幻」误当成「英语水平高」，进而放宽难度、减少讲解。

本规格用四条结构性约束替代分类：

- 主题是**自由文本**（标签 + 关键词），可增删改，没有白名单；
- **显式偏好**与**行为推断**分开存放，后者只影响排序、不落盘成权重；
- 行为信号**按时间衰减 + 上限**，一次点击不会永久改变推荐；
- 兴趣**不进入**任何能力、难度、掌握度、计划时长的计算路径。

## 2. 长期规格（L1–L10，逐条对应补充要求）

### L1 任意主题的增、改、删
- 数据：`InterestTopic { id, label, keywords[], source: 'explicit'|'suggested', weight 0–1, createdAt, updatedAt }`。
- `label` 是用户自由输入（中英文、含分隔符均可）；`keywords` 由标签自动拆分，也可用户改写，用于与材料主题匹配。
- 允许重名归一化（大小写/空白/标点），重复添加返回 `error` 而不是静默合并。
- 删除是硬删除；历史学习记录不受影响。

### L2 默认分类只是建议
- `SUGGESTED_INTERESTS` 只用于 UI 的「建议（点一下加入）」区，**不参与**任何校验、过滤或允许列表。
- 采纳后 `source = 'suggested'`，随后与自定义主题完全等价（可改权重/关键词/删除）。
- 没有「未知分类」的兜底归类：材料主题永远来自真实 `Passage.topic/title`。

### L3 可以选与画像无关的材料
- 推荐只按**材料是否存在**过滤（真实 `Passage`），从不按兴趣过滤。
- 画像之外的候选必须以 `Explore something new` 出现，而不是被隐藏。
- 用户也可以完全跳过推荐，用「自定义主题」直接开单元——只要有真实材料。

### L4 推荐综合六类输入
排序分数（当前实现，`miniUnitSelection.recommendThemes`）：

```
score = 材料数量×2 + 薄弱词×3 + 可观察语法×2
      + (显式兴趣命中 ? 4 + 2×weight : 0)
      + (当前进行中单元同主题 ? 2.5 : 0)
      + 1.5 × 近期行为权重(0–1)
      − 4 × 近 14 天完成过的同主题单元数
      − 4（最近用过的主题/材料）
      − 2（平均词数 > 900）
```

- 六类输入中：显式偏好、近期选择/完成（阅读、导入、单元）、当前 Mini Unit、能力与难度（薄弱词/语法/材料难度）都进入分数；可用真实材料是**前置条件**。
- 难度只影响「材料是否合适」的次要权重，**兴趣不改变 `estimatedDifficulty`**。

### L5 一次行为不会永久改变权重
- 行为信号**每次实时计算**（`activitySignals`），从不写回 `settings.interests`。
- 信号权重：阅读 0.4 / 导入 0.15 / 完成单元 0.3；指数衰减 `exp(-days/21)`；单主题封顶 1。
- 写测试保证：一次真实阅读后，画像对象的 JSON 完全不变。

### L6 保留探索空间
- 画像非空时，推荐最多 3 条，其中**至少 1 条**是不命中兴趣、也不命中当前单元的主题（有真实材料才出现）。
- 探索比例 `profile.exploration` 默认 0.34，可在 0–0.6 内调整。
- 若所有候选都与画像/行为相关，则不强行制造探索位——并在 UI 里如实展示理由。

### L7 显式偏好优先于行为推断
- 理由优先级：`interests` > `unit` > `recent` > `explore`（互斥分类）。
- 同分时显式兴趣主题排在前面；行为只能提升「非兴趣主题」的排序与理由。
- 用户把某主题加入画像 = 显式偏好，立即生效；删除即立即失效。

### L8 画像可查看、调整、重置
- 单元创建页常驻面板：主题 chips（★ = 高权重）、添加输入框、删除 ×、点击改名、建议区、重置按钮、行为证据条数与探索比例。
- 重置清空主题、保留 `resets` 计数（用于显示「已重置 N 次」），探索比例回到默认。
- 画像随 `settings` 持久化（IndexedDB），导出备份携带；**不新增 store、不升 DB 版本**。

### L9 兴趣 ≠ 英语能力
- 画像对象没有任何能力字段（无 level/score/CEFR）。
- 兴趣不参与：难度估计、目标词预算、掌握度、计划时长、复习间隔。
- 推荐文案不包含「你水平较高」类推断；只有材料证据（词数、薄弱词、语法结构）。
- 测试：同一材料在「有兴趣 / 无兴趣」下 `estimatedDifficulty`、`difficultyConfidence`、`targetWords.length` 完全一致。

### L10 不反复推荐同一主题的相似内容
- 近 14 天完成过同主题单元 → 分数 −4/个，且**排序硬规则**：`repeat = true` 的候选一律排在未重复候选之后。
- 仍会展示（有真实材料就可以选），但卡片明确标注「刚完成过同主题单元：这条推荐已降权」。
- 不永久拉黑：14 天窗口过后自动恢复；兴趣权重不受影响。

## 3. 推荐理由（对用户可见）

| reasonKind | 英文标签（上屏） | 中文说明 |
| --- | --- | --- |
| `interests` | Based on your interests | 基于你的兴趣 |
| `recent` | Based on your recent activity | 基于你的近期活动 |
| `unit` | Related to your Mini Unit | 与你的 Mini Unit 相关 |
| `explore` | Explore something new | 探索新主题 |

- 每条推荐都带 `whyRecommended`：材料事实（几篇、标题）、兴趣命中、近期行为次数、薄弱词、语法结构。
- 证据不足时追加「学情证据有限」；整体个性化不足时页面顶部给出**明确说明**（不假装精准）。

## 4. 数据与存储

| 项 | 值 |
| --- | --- |
| 存储位置 | `Settings.interests?: InterestProfile`（可选字段，旧数据自动补默认） |
| 版本 | 不升 DB 版本（仍为 v5），无迁移 |
| 归一化 | `normalizeProfile()` 去重、裁权重到 0–1、丢弃非法项、探索比例夹到 0–0.6 |
| 备份 | 随设置导出/导入；损坏数据不阻塞启动 |

## 6. 明确不做

- 不做自动兴趣聚类、不做 LLM 猜测兴趣（无凭据、不可验证）。
- 不把兴趣写进 `Passage`/`Word`/掌握度模型。
- 不因兴趣放宽阅读理解门槛或跳过预教。
- 不做「相似内容」的语义去重（同一主题下多篇文章仍可推荐，只是理由与顺序不同）——留给后续 Input Hub 的主题聚合。

## 7. 与 Phase 8 主体的关系

兴趣画像服务于 **Real Input Hub**：用户从任意来源（粘贴/URL/OCR/文件）带来真实材料后，
Hub 必须能回答「这段材料值不值得读、和我的目标有什么关系」——兴趣画像只提供**排序与理由**，
不替代材料真实性、可追溯性与难度判断。
