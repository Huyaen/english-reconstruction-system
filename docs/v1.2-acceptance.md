# v1.2 候选版使用与验收

本分支包含第二阶段功能；合并与日常数据库升级需另行最终验收。不要将测试构建部署到日常地址。

## 阅读原句填空

在已导入的阅读材料里点击原词，标为「不认识」或「模糊」，保存后从首页「原句填空 · 来自阅读标记」进入。输入原文中的实际形式并按 Enter；词头提示、查看答案和错词重练均单独标为辅助，不计首次独立正确。每次提交成功即保存独立证据；退出或刷新结束本轮，未提交输入不记成绩。可返回原阅读材料查看来源。

答案来自保存文章的确切句子与词形，不生成替代原文。重复词、关联不明、缺中文释义、词库释义歧义、AI 来源、句子位置不能核验时排除。复数、时态采用保守词形关联；派生形式可在阅读侧栏明确关联到已有词头。判定大小写与连字符，统一弯撇号及连续空白，其他标点保持严格。

此功能是「回忆原文」，不能证明其他表达不合理；词库之外所有同义表达无法自动穷举。阅读接触、选择题、拼写、语境填空分别留痕；填空不修改词汇 FSRS、到期时间、旧 ReviewRecord 或掌握度。

## 中断后的回归模式

多日中断或到期量超过预算时，首页提供可选入口。设置 30 / 50 / 100 / 150，或自定义 1–500；时间预算按原计划每词 0.35 分钟进一步限制数量。已做的不同复习词计入当天上限；新词首次作答不冒充到期复习。

保留原 DailyPlan 及暂停任务，显示暂缓原因；其他模块继续。同日同预算与上限维持固定分配，刷新和部分复习后重排不补入更多词；调整预算时保留任务历史，已投入及其他模块所占时间不能被静默删除。正常复习可主动退出数量限制。

排序同时使用到期、FSRS 遗忘风险、近期错误、薄弱词及词书覆盖，至少 25% 名额保留给最久积压的词（不足四名额时每四天保底一次）。未呈现的词保持原到期时间。估算只在「每日完成、无新增到期、每词一轮」假设下给出学习日数量，不承诺具体日期。

## 数据与备份

IndexedDB v8 → v9 只增加 `clozeAttempts`，回归分配保存在现有 `dailyPlans` 的可选字段。完整 v9 JSON 含填空证据和回归计划；旧 v1–v8 格式由现有验证器识别并补空新表。实际 v8 迁移与旧备份往返须另见运行日志，不能将格式识别等同于穷举全部历史备份。

v1.1 程序不能直接打开升级后的 v9 数据库；回退 Git 不会降级 IndexedDB。回退需保留 v9 完整备份，并在另外的浏览器配置或来源使用升级前 v8 备份；新填空证据无法写回旧程序。

自动备份沿用 v1.1 授权目录、串行任务、事件去重、写后结构与内容核验、清单内最近 14 份保留。权限过期需用户重新授权；清理不扫描或删除清单外文件，因此意外中断留下的未追踪文件可能额外保留。浏览器关闭、断电和磁盘故障不保证最新一轮已落盘；请看最近成功时间。API Key 不进入完整 JSON。

## 重跑验证

```powershell
npx tsc --noEmit
npm test
npm run build
npm run build:test
```

`scripts/v1.2-e2e.mjs` 是实际使用的浏览器驱动，仅连接独立 Edge 的 `127.0.0.1:9395`，仅接受 `http://127.0.0.1:4196/` 测试标签页。使用全新独立 profile，以 `dist-test` 启动独立端口，禁止日常配置开启调试端口。目录授权须由用户在原生浏览器提示中完成。

准备仓库外的测试目录，包含已经脱敏的真实词书测试快照 `before-catchup.json`（v9，含至少 600 词，无活动会话，初始无填空记录时先运行 cloze）、`before-v8.json`（真正升级前快照）及官方原文节选 `alice-reading.txt`。运行 cloze 后将其已保存状态作为新的 before-catchup 快照；本轮基线包含 4 条填空证据。文章来源是 Project Gutenberg #11 的 Alice Chapter I，保存原文后从正常阅读 UI 标记 get / nothing / once，不是 AI 生成句子。

```powershell
$env:CIJIAN_E2E_DIR = '仓库外的测试资料目录'
$env:CIJIAN_E2E_OUTPUT = '仓库外的测试日志目录'
node --import tsx scripts/v1.2-e2e.mjs upgrade
node --import tsx scripts/v1.2-e2e.mjs cloze
node --import tsx scripts/v1.2-e2e.mjs catchup
node --import tsx scripts/v1.2-e2e.mjs restore-regression
```

upgrade 必须从同一测试配置的实际 v8 数据库启动 v9 后执行；不要在日常库执行。catchup 明确将真实词书的 600 词构造成隔离积压情景，并仅在测试页面模拟跨日；记录由实际题目输入产生，最终恢复前快照。失败时保留日志检查后再恢复测试环境，禁止用通过标记替代真实结果。
