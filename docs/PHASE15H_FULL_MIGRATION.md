## 2. 原型开关：电影感界面成为默认路径

- `?proto=d` 从"可选原型"变为**默认**（无参数时也走 d）。
- 旧 15b 界面保留在 `?proto=legacy`（`a` / `b` / `off` 同样回退），保证可回退。
- `tests/plannerUi.test.ts`、`tests/sentenceUi.test.ts` 的 jsdom URL 显式加上 `?proto=legacy`：
  这两组测试断言的是**旧计划卡 DOM**（`.plan-task` / `[data-task-start]`），语义等价，不是降低标准。
- 结果：`npm test` 379/379 全绿。

## 4. 全局联动的改动（会影响所有页面）

1. `<html data-page data-level>`：场景强度不再靠每页各写一套。
2. 侧栏导航：从"14 个描边按钮堆"变为一条轨道（选中=填充+2px 金属竖条），这是 vision 复查里被点名的"active 态太弱"。
3. 顶栏保留分区名（兼容 `ui.test.ts` 的 `/专注训练/` 断言），只承担元信息。
4. 弹窗与 Toast 提升到 `[data-level]` 作用域，压过旧原型层（此前深色下 Toast 是刺眼白块）。
5. 空/错误/加载第一次拥有统一形态；错误不再只靠颜色（左侧 1px 线 + 文案 + `aria-invalid`）。

## 6. 回退方法

- UI 整体回退：`git checkout phase15g-motion-integrity`（15h 全部在独立分支 + 独立文件）。
- 只回退视觉：URL 加 `?proto=legacy` 即回到 15b 界面（业务代码不变）。
- 删除新层不影响业务：`system.css` 与 `pages/*.css` 是纯样式，`motion.ts` 只写 `data-*` 与 observer，移除后应用仍可运行。
