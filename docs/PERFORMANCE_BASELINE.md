# 性能基线与长会话观测（Phase 14）

**这些数字来自合成数据和本机无头 Edge，不是用户真实长期数据，也不是手机实测。**

## 1. 浏览器基准

运行：`node scripts/phase13-benchmark.mjs`（需要 `dist-test` 4173 + 独立 Edge CDP 9233）。
数据：A 空；C 3,000 词 / 6,000 记录；D 12,000 词 / 30,000 记录。

| 数据集 | 首屏 median | p95 | worst | IndexedDB 全读 | 今日计划 | 备份 JSON |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A 空 | 123 ms | 132 ms | 132 ms | — | — | — |
| C 日常 | 248 ms | 391 ms | 391 ms | 108 ms | 36 ms | 4.1 MB |
| D 压力 | 1,180 ms | 1,448 ms | 1,448 ms | 530 ms | 254 ms | 17.8 MB |

口径：3 次冷启动样本；`readyMs` 为导航到应用首屏可交互的时间，包含 IndexedDB 读取。D 数据集首屏明显变慢，属于已知边界，不宣称“大数据也很快”。

## 3. 长会话加速观测

`scripts/phase14-long-session.mjs` 在测试构建中循环切换 14 个页面 80 轮：

| 指标 | 首轮 | 末轮 |
| --- | ---: | ---: |
| usedJSHeapSize | 8,177,807 B | 8,343,278 B |
| DOM 节点 | 142 | 142 |
| `#main` HTML 长度 | 3,729 | 3,729 |
| JS 异常 | 0 | 0 |

堆增长约 **0.16 MB**，DOM 节点不增长。这是**加速代理**，不能证明 4 小时真实使用一定稳定；真实 4 小时仍需用户设备验收。

## 4. 已知性能边界

- 大数据集 D 首屏 1.2–1.6 s，未达到“任何数据量都秒开”的虚假目标。
- 性能样本是 3 次，不是统计显著性研究。
- 移动端只是视口模拟；真实低端手机 CPU/内存未测。
- 没有用 `performance.memory` 以外的堆快照/分配追踪，不能排除低频泄漏。
