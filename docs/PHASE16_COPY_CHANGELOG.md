## 5. 顺手修掉的非文案问题（都记在这里，避免和文案混在一起）

1. **开发用原型切换器**（A · Obsidian / B · Studio / D · Cinematic / 15b 基线）出现在上线页面底部。现在只在 URL 显式带 `?proto=` 时渲染，正常使用不再出现。
2. **推荐理由徽标中英双轨**：`基于你的兴趣 · Based on your interests` 同时显示。现在只显示中文，`reasonTag` 字段本身也统一成中文。
3. **`<meta name="apple-mobile-web-app-capable">` 的弃用警告**：补上 `mobile-web-app-capable`，控制台不再报 deprecated。
4. **对比度脚本在主题过渡中途采样**：`.d-quiet` 有独立的 160ms `color` 过渡，脚本只等 body 与 `.d-row`，把浅色主题的中间色 `#414B58` 当成最终色，误报 2.25:1。改成"等页面上所有动画/过渡都跑完再采样"后，同一套页面 dark / light 都是 **225 检查 / 0 失败**（实测该按钮最终色 `rgb(164,177,192)` 对 `rgb(8,9,11)` ≈ 8.6:1）。
